    Working in Tintquarry

    Open an image to start a project. Import more images from the Layers panel or drop them into the canvas.

    Drag the selected layer with Move. Brush adds a paint layer when needed. Eraser works on paint layers. Use Fit to reset the view.

    Save a .tq project to keep layers editable. Export PNG to share the visible composite.
